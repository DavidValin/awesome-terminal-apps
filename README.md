# awesome-terminal-apps
A curated list of awesome apps that run purely on the terminal

### Communication
* [aloo](https://github.com/DavidValin/aloo) - Secure P2P terminal walky talky / text / file transfer communication with public/private channels, DMs, and several strong encryption algorithms. Support global hotkey for voice push to talk.
* [iamb](https://github.com/ulyssa/iamb) - Awesome client for matrix messaging (federated protocol)
* [phetch](https://github.com/xvxx/phetch) - Gopher client (used to navigate through menus, read text, download files from Gopher servers)
* [repartee](https://repart.ee) - Awesome irc client
* [tin](http://www.tin.org) - Client for NNTP (Network News Transfer Protocol), an old but powerful federated protocol to share news, articles and discussion forums

### Business
* [Tiny Business Simulator](https://github.com/DavidValin/tiny-business-simulator) - Simulate a business using .txt files per product, monthly and yearly profit goals and get a simulation (graph + counts). It exports in text files which might be used to interoperate with AI models.

### GenAI

* [task you](https://github.com/bborn/taskyou) - Kanban board with GenAI agents delegation, allows you to work on paralell tickets and monitoring them
* [llamafile](https://github.com/mozilla-ai/llamafile) - Turn a gguf model into a portable program that runs the model with llama.cpp and runs in Mac, Linux and Windows (the same file with no external installations)
* [llama.cpp](https://llama.app) - Run any AI model in gguf format locally as fast as possible (supports all GPUs and CPU only) with lots of options
* [vtmate](https://github.com/DavidValin/vtmate) - Live voice conversation with local models with voice interruption, push to talk support (supports input txt prompts from files and pipes), create automated voice debates between AI agents and participate in between (very useful to learn) and voice-read txt files. supports export to audio files. extremely low latency, many voices and languages. very configurable and versatile
* [aichat](https://github.com/sigoden/aichat) - Chat with AI models in the terminal, supports piping data, save sessions, RAG and many providers
* [Universal Prompt Language (UPL)](https://github.com/DavidValin/universal-prompt-language) - Create, manage and build reusable dynamic prompts using variables and rendering logic. Allows you to work a single prompt and use it for many different use cases
* [opencode](https://opencode.ai) - Automated LLM coding platform (local / remote models), automatically changes the codebase via tool calls, has Re-Act loops which loops between LLM responses and tools till it achieves the goal. massive tool
* [pi](https://pi.dev) - the same as opencode, quite configurable
* [claude](https://www.claudecli.org) - CLI to operate frontier models from Antrophic
* [picoclaw](https://github.com/sipeed/picoclaw) - ultralightway single-agent personal utility and device edge computing designed to run on cheap $10 IoT hardware using under 10 MB of RAM

### Cryptography
* [otp](https://github.com/DavidValin/otp) - "One Time Pad" (Vernan Cipher) cli. Encrypts/Decrypt using One Time Pad (the only true quantum proof algorithm that exists). Manage a keychain with a key pair per contact with consumption tracking and security measures to prevent otp algorithm accidental mismanagement. 
* [gpg](https://www.gnupg.org) - The swiss army for encryption/decryption. Support most of the cryptographic methods. It also has a keychain to store keys locally
* [srm](https://sourceforge.net/projects/srm/) - Remove files securely by overriding its content. Useful to destroy private keys safely
